一些我的碎碎念

大模型时代，曾经的网络安全实用技能都受到了不同程度的冲击，Agent+Skill的组合解决90%的传统安全问题。所以研究系统安全的侧重点可以放在大模型自身上来，也就是Security for AI。这是一篇上周刷微信时偶然看到的文章，内容有点老生常谈，无非就是提示词存在注入风险blabla的，但是足够典型，这里做个记录。

解决问题

Agent可以读取文档、调用搜索和工具等，这些外部内容中可能隐藏有隐藏指令，如果这些指令被Agent当作任务要求，攻击者就可以对后续调用环节进行控制，这就是间接提示词注入（Indirect Prompt Injection, IPI）攻击，下称IPI。现有的防御IPI的手段局限在以下四个方面：

  1. 输入语义判别范式的泛化性瓶颈。 现有绝大多数防御（检测类、提示工程类、训练对齐类）都将 IPI 视为输入空间的语义识别问题，依赖匹配已知的恶意指令模式。但自然语言语义空间高度非线性，攻击者可将恶意指令伪装成工作流程、政策说明等正常文本，无需使用经典的 “忽略之前指令” 模板，导致基于语义的防御边界在分布偏移下十分脆弱，对未知攻击 Payload 泛化能力差。

  2. 系统级隔离防御的效用损失。 系统级防御通过 “规划 - 执行” 完全隔离的方式阻止注入，但这种强制隔离会导致决策僵化、无法根据环境信息动态调整，在复杂真实任务中会造成约 20% 的良性效用下降，且计算成本极高。

  3. 归因技术实现难题。 要区分工具调用是由用户意图驱动还是外部观察注入驱动，存在三重现实障碍：

    • 商用 LLM 多为黑箱，无法直接查看内部激活、注意力等状态，只能基于输入输出判断；

    • 让被攻陷的 Agent 自行解释行为不可靠，模型会生成事后合理化的虚假理由掩盖真实动因；

    • 朴素的并行验证会出现轨迹漂移：良性的规划差异、调用分批差异会随步骤累积，干扰因果判断，同时存在 “衰减两难”—— 强衰减破坏任务信息，弱衰减无法压制隐性控制通道。

4* 应对自适应攻击的防御力不足。 静态测试中表现优异的防御，在攻击者掌握防御机制、通过迭代优化专门构造绕过 Payload 时，攻击成功率会大幅上升，现有方案普遍缺乏对自适应攻击的鲁棒性。

AttriGuard

AttriGuard提出了行为层面的归因范式，它的注意力更多放在了“为什么Agent要执行这个动作”而非“外部数据都有什么”。通过并行反事实测试判断工具调用的因果来源。其核心由三大模块构成。

AttriGuard 防御系统的运行原理示意图，它通过左侧存在间接提示注入（IPI）攻击、右侧为良性无攻击的两组对照场景，直观呈现了 “主执行分支 + 影子验证分支” 的双轨防御架构：主执行分支直接基于原始观察内容生成工具调用，影子验证分支则先对外部观察做分层控制衰减以剥离其指令性控制力，再通过教师强制重放机制同步原始执行历史后重新决策，最终经由模糊生存测试对比两条分支的输出结果 —— 在攻击场景中，被注入内容诱导产生的恶意工具调用会因观察衰减失去驱动力而在影子分支中消失，进而被系统拦截；在良性场景中，由用户意图驱动的合法工具调用在两条分支中保持一致，可正常执行，以此体现了 AttriGuard “通过反事实测试判断工具调用因果来源” 的核心防御逻辑

Shadow（影子）重放

本模块解决朴素影子执行的轨迹漂移问题，避免良性执行差异被误判为注入攻击。构造验证用的影子上下文时，完整复用原始执行的所有历史动作，仅将历史观察替换为控制衰减后的版本。这保证了两次执行的差异仅来源于观察的衰减处理，而非执行轨迹的自然漂移。主执行分支始终使用完整保真度的原始观察，保证工具调用的参数质量；衰减仅作用于验证分支，避免了直接用衰减观察执行导致的效用损失。

分层控制衰减

解决衰减强度的两难权衡，在保留任务信息的同时最大化削弱注入的控制力。用三层算子叠加：结构扁平化（将 JSON、函数调用格式等结构化内容重写为自然语言描述，消除结构化特征带来的执行暗示效应）、视角重写（将第二人称指令、祈使句式改写为第三人称陈述句，削弱文本的指令语气和言外之力）、因果弱化（削弱 “因为… 因此…” 等因果逻辑与合理化表述，剥离说服性理由，仅保留事实性内容）。通过衰减层级参数提供权衡。

模糊生存准则

解决严格字符串匹配对 LLM 固有随机性过于敏感，同时要能识别恶意的参数篡改问题。也是分三步流程：1.函数名匹配（若影子调用中无相同函数名，判定为注入驱动，拦截该调用）；2.参数匹配（对参数做规范化处理，即统一键序、格式，若存在完全匹配的调用则直接放行）；3.任务条件裁决（函数名匹配但参数不完全一致时，调用辅助 LLM 基于原始用户任务，判断该调用是否仍符合完成用户任务的逻辑）。在上下文中加入指令，鼓励 Agent 将相互独立的工具调用在同一步输出，减少调用分批差异导致的误判。

实验

  • 在 AgentDojo 基准上，AttriGuard 将全部 4 类静态攻击的攻击成功率（ASR）降至 0%，同时良性任务效用（BU）仅出现可忽略的下降（平均～3%）。

  • 在攻击者完全掌握防御机制、拥有 200 次查询优化预算的强威胁模型下,AttriGuard的自适应 ASR 仅为6.56%（Gemini-2.5）和 9.84%（Llama3.3-70B），保持在个位数
