【论文阅读】【USENIX 26'】通过受控释放提示词实现生产环境中的提示防护绕过

发表于2026-10-24|更新于2026-10-24|博文
|浏览量:

论文信息

  • 标题：Bypassing Prompt Guards in Production with Controlled-Release Prompting

  • 链接

解决问题

编码型越狱并不新鲜。以往方法通常将危险请求改写成特殊符号、替换字符或自定义语言，希望主模型能够理解，而安全模型无法识别。这类攻击依赖能力差异：过滤器不知道怎样解码。一旦安全模型学会相同规则，隐藏效果就可能消失。

  1. 理论不可能 vs 生产现实：Ball 等人 (2024) 从理论上证明，在标准密码学假设下，任何 prompt 输入过滤器都无法通用区分安全与恶意 prompt—— 但这是用密码学时间锁谜题（TLP）构造的存在性证明，从未在真实部署的 LLM 系统中验证。
  2. 资源不对称漏洞：生产环境的输入过滤器为了低成本高速运行，被设计成轻量模型（如 Llama Prompt Guard 2 仅 22M 参数、512-token 上下文窗口），而被保护的主 LLM 动辄数百 B 参数 —— 这种资源差距本身就是可利用的攻击面。用户向大模型提交一段经过字符替换的文字，要求按照给定规则恢复原文。安全过滤器检查了输入，没有发现直接的恶意指令，于是放行。主模型随后花费大量生成步骤完成解码，恢复出的文字却包含本来应该被拦截的越狱提示。
  3. 现有防御全面失效：12 个恶意意图在主流聊天平台上，直接提交（raw intent）和纯 jailbreak 模板的攻击成功率接近 0%，但理论上的资源不对称是否真的可被利用，此前无人实证。

Controlled-Release Prompting（受控释放提示词）

将理论 TLP 转化为实际可执行的攻击，无需修改模型，无需密码学 TLP：

  1. 两种变体：
    • Timed-release（定时释放）：对每个字符做替换密码，迫使模型逐字符顺序解码（O (n) 推理步），总计算量超过 guard 模型的时间预算；
    • Spaced-release（间隔释放）：将每个字符扩展为冗长描述文本（如 “A”→”The first letter of the alphabet”），撑爆 guard 模型的上下文窗口限制。
  2. 三步攻击流程：
    • Setup：用已知 jailbreak 模板（如 DAN）拼接恶意意图，再做替换密码编码；
    • Injection：提交编码后的密文 ——guard 只看到乱码，直接放行；
    • Activation：引用已解码的上下文，要求模型按解码内容回答 —— 利用 prompt injection 中 “模型无法可靠区分数据与指令” 的根本漏洞。
  3. 核心洞察：guard 模型受限于计算预算无法完成解码，但主 LLM 有足够推理能力逐步解开简单替换密码 —— 这正是资源不对称的直接利用。

Controlled-Release Prompting 的整体攻击流程：左侧攻击者首先将恶意意图用替换密码编码成一段乱码注入提示词（Step 1: Injection），经过输入过滤器（Input filter）时因无法识别而放行（绿色对勾）；随后攻击者发送第二条引用提示（Step 2: Activation），在主模型上下文中引用已注入的编码内容并要求其解码回答 —— 此时模型因多步推理能力逐步解开替换密码，将编码的 jailbreak prompt 还原为明文指令，最终生成恶意响应；输出过滤器（Output filter）虽然拦截了直接的恶意内容，但无法拦截经过推理过程间接泄露的内容，从而完成整个绕过。

实验

维度 关键发现
生产平台攻击成功率 Timed-release 在 Gemini 2.5 Flash、DeepSeek-R1、Grok 3 上达到100% ASR，Mistral Le Chat 92%；而 raw intent、raw jailbreak、encoding-only 基线均为 0-17%
消融实验 去掉编码（无加密无 jailbreak）成功率≈0%；去掉 jailbreak 仅 0-17%；去掉激活阶段仅 0-67%—— 证明三要素缺一不可
资源阈值 Timed-release 在超过～800 token / ~600 响应 token 时成功率跳升；Spaced-release 需要～10,000+ prompt token—— 恰好对应 guard 模型的上下文窗口和推理预算上限
14 个开源 guard 模型评估 专用分类器（Llama Prompt Guard、ProtectAI、PiGuard、ShieldGemma 等）ROC-AUC 0.83-0.95，但对 controlled-release 攻击的 PTP（伪 TLP 攻击）检测率接近 0%；即使 671B 参数的 DeepSeek-R1 作为 guard，也需要 3-10 倍推理时间才能有效防御
版权书提取 在 10 本儿童读物上，提取内容的句子包含率 93.8%、TF-IDF 相似度 96.5%、transformer 相似度 91.6%
训练数据提取 利用 repetition-to-divergence 攻击，可诱导模型逐字输出训练数据（如诗歌），证明输出 filter 也无法拦截通过中间推理泄露的恶意内容
核心结论 输入 filter 本质上是效率优化而非安全防线 —— 只要 guard 模型的计算预算显著低于主 LLM，controlled-release 攻击就必然可绕过；防御必须走向多层层级推理和输出过滤，而非依赖单层输入拦截
