WEB-683

绕过题目，源码：

参数 秀 必须是数字，数值要落在 [5184000, 7776000] 区间（大约 60~90 天，单位秒），然后执行 sleep((int)$_GET['秀']) 再输出 flag。考点是 PHP 弱类型 / 数字字符串解析规则的不一致。

考点是 PHP 弱类型 / 数字字符串解析规则的不一致：

  1. is_numeric() 接受科学计数法：6e6、0.6e7、.6e7 都算数字；但十六进制 0x10 在 PHP 7+ 不算。
  2. 比较运算按“数值”比较：".6e7" < 5184000 会被当成浮点数 6 000 000 来比，从而落在区间内。
  3. (int) 强转走的是 strtol 语义：从字符串开头读整数，遇到 .、e 就停止。
    • .6e7 → 首字符是 .，一个整数位都没读到 → (int) = 0
    • 5.2e6 → 读到 5 就停 → (int) = 5（所以会睡 5 秒）
  4. 于是构造出“比较时是 600 万，强转后是 0”的字符串，同时满足两边。

payload：?秀=.6e7
