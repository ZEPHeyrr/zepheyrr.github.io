这是你沐师傅的站的流量，最近你沐师傅去跟着某讯搭了一个WP平台后发了一篇文章再测试了一下自己的网站就再也没去管过平台了。结果被某位名字貌似大概可能叫**g4_simon**的大黑阔给hack掉了网站，并进行了一些操作拿到了沐师傅放在平台里的信息。由于沐师傅说他摆烂了不想自己研究，于是将流量附件放了出来叫大家来帮忙找一找。 找到三段**你觉得像flag的内容**并用下划线组合，即ctfshow{A1_A2_A3}，找不到就算了，摆烂了。 ~~如果交不上就算了，摆烂了~~ (其实签到题是PC1和CP1)

Step4-识别解码webshell流量

找找看有没有getshell的特征,寻找之前在包中找到的可以文件a.php。过滤器http.request.uri == "/a.php"，点一个POST右键，追踪TCP流。

这是一个 PHP 一句话/数据库管理木马,特征非常明显：asenc、asoutput、echo "随机marker"、base64_decode(substr($_POST[...],2)) —— 这是 哥斯拉（Godzilla）PHP shell。a.php 本身只有 32 字节，就是一个 eval($_POST['mumuzi']) 的壳，真正的功能代码是每次 POST 进去的。

命令在 fdb0a19e409768 字段里，解码规则是：

  1. URL 解码；
  2. 去掉开头 2 个随机字符（shell 里的 substr(...,2)）；
  3. Base64 解码。

几个小技巧

  1. 加列：右键 http.request.method、http.request.uri、http.response.code、tcp.stream → Apply as Column，之后一眼就能看出请求类型和状态。
  2. 跳帧：Ctrl+G 输入 3664 直接跳到指定帧。
  3. 找字符串：Ctrl+F 比 frame contains "..." 好用；frame contains 的右值要写十六进制字节串。
  4. 整段会话：右键 → Follow → TCP Stream，比逐个包看 body 全。
  5. 批量导出：File → Export Objects → HTTP，可以把 a(23).php、post.php、secret.zip 等全部导出再离线看。
  6. 响应体被压缩/分片：如果响应看不到正文，确认 Preferences → Protocols → HTTP → Uncompress entity bodies 已勾选；POST 的 body 分片时，点最后一个重组包（列表里带 [Reassembled in #] 的那条）。
  7. HTTP 统计：Statistics → HTTP → Requests 能看到所有请求的树状列表，按 URI 分组，很适合先看全貌再下钻。
